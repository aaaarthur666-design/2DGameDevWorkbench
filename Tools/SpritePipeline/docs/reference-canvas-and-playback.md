# 原图像素修改与播放检查

## 原图修改

从作品库的角色卡片点击“编辑原图”，或在生成页上传／选择原图后点击“在像素画布中修改原图”。角色 Sheet 会使用生成页显示的那一张参考帧。

沿用铅笔、橡皮、吸管、填充、框选、撤销等像素工具。点击“保存原图修改副本”，再点击“作为新原图送到生成页”。新原图同时保存为作品库中的一个新角色；下次生成会将修改后的像素复制到任务参考图。移送本身不开始生成。

原始角色与已有任务参考图保持不变。修改版本保留朝向、持刀手、锚点和检查设定；旧调色板、剪影及 Sheet 路径不复用。每次保存逐像素核对 RGBA；过期窗口不能覆盖新版本。同一个已保存版本重复移送只产生一件作品。画布草稿保存于本地 reference-edits，不创建空生成任务。未保存的修改需要先保存；全透明原图不能移送。

## 播放检查

播放器读取当前候选的全部实际帧，支持 1–64 帧，与当前动画是否为 16 帧无关。

- 单次播放：完整播放后停留在最后一帧。
- 循环播放：最后一帧之后回到第一帧。
- 往返循环：正向播放到末帧，再反向回到首帧；转折端点不重复停留。
- 慢放／正常／快放：项目 FPS 的 0.5 倍／1 倍／2 倍，最高 60 FPS；也可直接输入 0.1–60 的播放 FPS。

支持暂停与从头播放。默认沿用动作的 FPS 和循环属性；修改播放设置只影响预览，不更改动作、生成、修补或导出规格。全部画面读取并核对当前版本后才开始播放；文件不一致时提示重新读取，不混播不同版本。

这些编辑与播放操作均在本机完成，不调用图片生成或视觉检查服务。
