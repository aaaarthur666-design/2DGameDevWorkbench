## 实现范围

- 生成按钮上方增加每张地图块独立的额外提示词，支持多行、清空、2000 字限制和完整请求文本预览。
- 浏览器草稿和 Pixelwork 源文件 ZIP 保存提示词；新扩展卡片及旧文件默认空文本。
- 队列保存完整提示词及服务商，批量卡片分别组合。重试和恢复不重新读取当前提示词；旧队列缺少快照时暂停并要求重新入队。
- 自动扩图启动时固定基础提示词和服务商。
- 新旧编辑器的整体图片生成都调用图片 API；移除两套镜像补全算法和本地模式选项。旧图片来源值保留兼容读取。
- 修正旧编辑器的整体层请求参数及返回相对图片地址的读取。
- Gemini 返回处理中跳过 `thought` 中间图片。

## 浏览器验证

在临时源码副本的 localhost:3001 上使用程序创建的 128 × 128 纯色测试图片，未点击任何真实生成服务：

- 输入中心地图的中文多行要求，完整预览包含基础约束及原文。
- 切换右侧地图块时输入框为空；输入另一段要求后保存，刷新页面可恢复右侧内容，切回中心仍保留中心原文。
- 输入框的 `maxLength` 为 2000，允许垂直拖动调整高度。
- API 未启用时显示设置入口且整体生成按钮禁用。
- 默认桌面布局及 375 × 812 窄屏抽屉中的输入框、计数和预览弹窗可用。

真实账号的权限、额度、网络及付费出图未验证；以上模拟服务结果不代表真实外部调用成功。接口格式依据见[地图拼接文档](map-stitcher.md#地图块额外提示词)。

## GPT Image 2 比例错误修复回归

新增 5504 × 3072 实际尺寸 PNG 回归：模拟接口读取 multipart 中的 `size=2064x1152` 并按此尺寸返回图片，最终合成为 5504 × 3072，原有实色和半透明像素逐字节一致。覆盖竖图、常见比例、非整倍数尺寸、小模板及超出 3:1 时不发送请求。

另测模拟接口忽略 `size` 返回 2 × 2 图片：任务为 failed，错误含模板/请求/返回三组尺寸，原始返回字节和诊断记录可从任务 outputs 找到，且无最终生成图。401 和缺少图片的响应同样保存诊断信息。中文额外要求在尺寸提示词适配后保持不变，记录中不含测试 API 密钥。既有 HTTP 与 MCP 契约测试通过。
