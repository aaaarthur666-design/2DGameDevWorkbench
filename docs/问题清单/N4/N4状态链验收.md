## 工具问题与拒绝行为

- **N4-01　登记与预览。** 原进度接口总取最新回包尾帧，提前截尾时用户会看到 f05；直接接受整段后也缺少具名状态图入口。现在从候选的确认记录派生状态图清单，当前段单独锁定或整段接受都可读取同一状态的冻结像素。阶段、实际帧号、回包索引、哈希及已有修复来源随图可查，历史计划无需迁移。
- **N4-02　分段复核目标。** 原分段评审同时收到全片终态 C 和段内目标 B。现在基础审核、独立专家和分段调整读取当前段的起态、目标与终点。全片评审保留全局目标并读取实际过渡边界。回归读取两段独立专家的证据快照，分别核对 A→B 和 B→C。
- **N4-03　快照完整性。** 原接续检查只覆盖已接受过渡的冻结帧。先单独锁定 B 再接受第一段时，还会存在一份独立确认的 B。分别改写这份 B 和移除过渡的冻结末帧，读图均返回冲突，执行器停止，第二段提交数为零。
- **拒绝。** 第一段直接拒绝时只登记 A。先锁定 B 再拒绝第一段时保留 B 及拒绝记录；恢复和重复推进均停在第一段。第二段拒绝时 A、B 保留，C 未登记，全片未组装。
