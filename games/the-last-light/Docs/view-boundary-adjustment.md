- 游戏默认最大化，恢复普通窗口时保留 1280×720；逻辑画面保留 640×360，等比显示。
- LevelRoot.camera_zoom 默认 0.5，镜头可见范围由 640×360 扩大到约 1280×720 世界单位。镜头边界读取导入地图 Sprite2D 的真实范围；出生后立即重置平滑定位，避免开场追镜头时裁掉人物。

## 手动验收

运行 GameRoot 主场景（F5，避免 F6 仅运行导入地图）。确认游戏最大化、可见范围更大；持续向左或右移动应被地图边缘挡住。顶部与底部已通过物理测试，不必为验收修改角色位置。重开后确认移动和交互正常。
